# Дитячий Alias — картинки

Невелика браузерна гра для дітей. Гравець пояснює зображення словами або жестами, не називаючи відповідь, а інші намагаються її вгадати. Інтерфейс доступний українською та англійською мовами.

## Як запустити

1. Завантажте або клонуйте репозиторій.
2. Відкрийте файл [`kids-alias-pictures.html`](kids-alias-pictures.html) у сучасному браузері.

Збірка, сервер і встановлення залежностей не потрібні. Гра працює локально; картки та рахунок не надсилаються в інтернет.

## Як грати

1. Виберіть категорію або залиште «Усі категорії» та встановіть тривалість раунду.
2. Натисніть «Почати раунд». Гравець пояснює картинку, не називаючи слово-відповідь.
3. Натисніть «Вірно (+1)», якщо слово вгадали, або «Пропустити», щоб перейти до іншої картки.

Відповідь до картки відображається під зображенням. Грати можна і без таймера.

## Можливості

- 500 карток у 10 категоріях.
- Вибір категорії та тривалості раунду.
- Випадковий порядок карток без повторів, доки не завершиться колода.
- Таймер, рахунок і скидання балів.
- Адаптивний інтерфейс для телефонів і комп’ютерів.
- Українська та англійська мови з перемикачем у верхній частині сторінки.
- Працює офлайн після завантаження файлу.
